# 🌍 Multilingual PDF Chatbot

A RAG-powered chatbot that answers questions from uploaded PDFs in 50+ languages!

## Features
- Upload multiple PDFs at once
- Ask questions in any language
- Auto language detection
- Conversation memory
- Source chunk display

## Built With
- LangChain + FAISS
- Groq AI
- HuggingFace Embeddings
- Streamlit
